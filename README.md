⚡ Welcome to the Docker Lab

This repository is more than a collection of Dockerfiles.

It is a hands-on Docker playground where every subproject focuses on a practical concept — from serving a static website with Apache to containerizing applications and eventually connecting Docker with CI/CD and cloud deployment.

Learn → Build → Containerize → Run → Debug → Deploy 🚀

Every project has its own README, so you can click into a project and get its complete setup, commands, architecture, troubleshooting.
